# 일일 노트

일일 노트는 날짜별 진행 맥락, 막힌 점, 중요한 관찰을 남깁니다. 오늘의 노트는 Obsidian의 **Open today's daily note** 명령으로 엽니다.

일일 기록은 개인 작업 일지에 가까우므로 실제 팀 공유가 필요하지 않은 민감한 내용을 이 공개 저장소에 남기지 마세요. 지속적으로 참고할 결정이나 지식은 각각 `05 Decisions/`, `06 Knowledge/`에 옮기고 일일 노트에서는 링크합니다.
