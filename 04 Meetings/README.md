# 회의 기록

회의 전에는 [[08 Templates/Meeting Note|회의록 템플릿]]으로 목적과 안건을 준비합니다. 회의 후에는 결정, 담당자, 다음 단계, 관련 프로젝트 링크를 채웁니다.

- 결정이 장기간 유효하거나 여러 팀에 영향을 주면 `05 Decisions/`에 별도 결정 기록을 만듭니다.
- 실행 작업은 팀 작업 추적 도구에 만들고 회의록에서 링크합니다.
- 회의 노트는 날짜를 포함한 제목으로 저장합니다. 예: `YYYY-MM-DD 제품 주간 회의`.

전체 목록은 [[09 Bases/Meetings.base|회의 Base]]에서 확인합니다.
