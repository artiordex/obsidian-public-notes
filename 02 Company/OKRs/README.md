# OKR 운영

기간별 OKR은 [[08 Templates/OKR|OKR 템플릿]]으로 만들고 이 폴더에 저장합니다. 분기나 반기처럼 팀이 정한 기간을 `period` 속성에 기록하고, 각 Key Result에는 측정 가능한 기준값과 목표값을 둡니다.

전체 목록은 [[09 Bases/OKRs.base|OKR Base]]에서 확인합니다. 정기 점검 때 현재값, 위험 요소, 필요한 결정을 갱신하고 관련 프로젝트를 연결합니다.
