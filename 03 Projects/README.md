# 프로젝트 운영

각 프로젝트에는 [[08 Templates/Project Note|프로젝트 템플릿]]으로 기준 노트를 하나 만듭니다. 기준 노트에는 결과, 성공 지표, 단일 책임자, 팀, 상태, 목표 날짜를 둡니다.

- 상태와 담당자 변경을 프로젝트 노트에 반영합니다.
- 회의록과 결정 기록을 프로젝트 노트에서 링크합니다.
- 실행 작업과 마감일은 팀 작업 추적 도구에 만들고 해당 항목을 링크합니다.
- 완료된 프로젝트는 삭제하지 말고 `archived` 상태로 바꿉니다.

전체 목록은 [[09 Bases/Projects.base|프로젝트 Base]]에서 확인합니다.
