# 인박스

새 아이디어, 질문, 읽을거리, 후속 작업을 빠르게 적고 주간 검토 때 분류합니다.

1. 기록할 때는 정리보다 포착을 우선합니다.
2. 주간 검토에서 각 항목을 프로젝트, 회의, 의사결정, 지식 문서, 실행 작업 중 하나로 옮깁니다.
3. 실행 작업은 GitHub Issues, Linear 등 팀의 작업 추적 도구에 만들고 Obsidian 노트에 링크합니다.
4. 옮긴 뒤 인박스 원본은 삭제하거나 관련 노트로 바꿉니다.

새 노트는 기본적으로 이 폴더에 생성됩니다. 검토가 끝난 노트를 목적에 맞는 폴더로 이동하세요.
