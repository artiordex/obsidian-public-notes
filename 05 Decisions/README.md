# 의사결정 기록

영향이 큰 선택을 [[08 Templates/Decision Record|의사결정 템플릿]]으로 남깁니다. 결론뿐 아니라 맥락, 고려한 대안, 기대 효과와 후속 검토 조건을 기록해야 나중에 판단을 이어갈 수 있습니다.

- 하나의 기록에는 하나의 결정만 둡니다.
- 결정 상태는 `proposed`, `accepted`, `rejected`, `superseded` 중 하나로 관리합니다.
- 결정이 바뀌면 기존 문서를 덮어쓰기보다 새 기록을 만들고 이전 결정과 연결합니다.
- 관련 프로젝트와 회의록 양쪽에서 결정 노트를 링크합니다.

전체 목록은 [[09 Bases/Decisions.base|의사결정 Base]]에서 확인합니다.
