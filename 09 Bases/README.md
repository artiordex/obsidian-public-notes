# 팀 현황 Base

Bases는 노트의 Properties를 표로 묶고 필터링하는 Obsidian 기본 기능입니다. 아래 목록은 `type`, `status`, `owner`, `team`, 날짜 속성으로 관리합니다.

- [[09 Bases/Projects.base|프로젝트]]
- [[09 Bases/Meetings.base|회의]]
- [[09 Bases/Decisions.base|의사결정]]
- [[09 Bases/OKRs.base|OKR]]
- [[09 Bases/Knowledge.base|지식 문서]]
- [[09 Bases/Research.base|사용자 조사]]

새 노트를 만들 때 해당 종류의 템플릿을 사용해야 Base에 자동으로 나타납니다.
