# 스타트업에서 Obsidian 활용하기

스타트업에서 Obsidian을 지식 허브로 쓰려면 폴더만 만드는 데서 끝나지 않습니다. 프로젝트, 회의, 결정, 재사용 지식을 같은 링크와 Properties로 연결하고, 반복 기록은 템플릿으로 시작합니다.

## 운영 구조

- `03 Projects/`: 결과와 성공 지표를 기준으로 각 프로젝트를 추적합니다.
- `04 Meetings/`: 회의 내용을 기록하고 관련 프로젝트와 결정을 연결합니다.
- `05 Decisions/`: 선택의 이유와 결과를 남깁니다.
- `06 Knowledge/`: 반복해서 쓸 지식, 운영 절차, 익명화된 사용자 조사 근거를 정리합니다.
- `07 Daily/`: 날짜별 업무 맥락을 보관합니다.

## Obsidian 기능 활용

- Properties는 `type`, `status`, `owner`, `team`, `date`처럼 반복되는 정보를 구조화합니다.
- Bases는 그 Properties를 기준으로 프로젝트, 회의, 결정, OKR을 모아 보는 표를 만듭니다.
- 내부 링크와 Backlinks는 프로젝트, 회의, 결정 사이의 맥락을 이어 줍니다.
- Templates와 Daily notes는 반복 기록을 빠르게 시작합니다.
- Canvas는 초기에 불확실한 아이디어, 사용자 여정, 시스템 관계를 시각적으로 정리합니다.

## 실행 작업 관리

회의록에 실행 항목을 남기되, 담당자와 마감일이 있는 일은 GitHub Issues, Linear 등 팀의 실행 도구에도 등록합니다. Obsidian에는 작업의 배경과 결정 근거를 연결해 실행 도구와 지식이 분리되지 않게 합니다.
