# 지식 문서

반복해서 참고할 개념, 절차, 문제 해결 방법은 [[08 Templates/Knowledge Note|지식 문서 템플릿]]으로 정리합니다. 사용자 조사 결과는 [[08 Templates/Research Note|조사 템플릿]]을 사용하고 식별 정보를 제거합니다.

- 팀이 실제로 따르는 절차는 `runbook`으로 표시하고 담당자와 검토 주기를 기록합니다.
- 외부 자료에서 가져온 내용에는 원문 링크와 확인 날짜를 둡니다.
- 적용 범위가 끝난 지식은 삭제하지 말고 `archived`로 표시합니다.
- 공개 사이트에 보여줄 문서는 검토한 뒤 `docs/`에 추가합니다.

전체 목록은 [[09 Bases/Knowledge.base|지식 Base]]에서 확인합니다. 현재 공개된 예시는 [개발자 실무 지식](../docs/developer-practical-knowledge.md)과 [Codex CLI 설치 방법](../docs/chatgpt-cli-install.md)입니다.

조사 기록은 [[09 Bases/Research.base|사용자 조사 Base]]에서 확인합니다.
